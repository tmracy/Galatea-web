# Galatea

**一个会记住你、也会过自己日子的语音 AI 伴侣。**

在线体验：[https://galateaagent.com/](https://galateaagent.com/)

这不是又一个对话框套大模型。Galatea 把角色、声音、记忆和生活时间线做成同一件作品：你来定义她是谁，用语音把呼吸还给她，然后她会在对话之外继续过自己的一天。

本仓库是产品的 Web 前端（Vue 3）。后端为独立 Flask 服务。两者一起构成完整的在线体验。

---

## 作品定位

面向个人作品集与产品展示。目标不是堆功能，而是证明一件完整的 AI 产品可以被做出来：有品牌、有角色、有记忆、有声音，并且已经部署上线。

适合用来说明：

- 如何把陪伴类 AI 从「会聊天」做成「像一个人」
- 如何处理流式对话、语音克隆、长期记忆与多通道隔离
- 如何把 Live2D、移动端布局和真实上线流程收成可交付产品

## 服务优势

**她记得你。**  
对话不是一次性问答。聊完后归档进长期记忆，新窗口会带着上一轮的痕迹重新开场。名字、住址、习惯可以说清楚，下次还能问回来。

**她有自己的声音。**  
支持文本和语音输入，回复逐句流出、逐句朗读。也可以上传一段参考音频，克隆成专属音色。Live2D 形象会跟着 TTS 响度做嘴型。

**她不聊天时也在生活。**  
生活模块按北京时间槽生成当天事件与情绪：愉快、精力、压力、想交流。同一时段不重复生成，夜里会休息。陪伴不再只发生在对话框里。

**通道是分开的。**  
日常陪伴、生活轨迹、生产力文件夹任务、情绪倾诉各自独立。心情不会误写入长期记忆，工作材料也不会混进闲聊。

**已经是上线产品，不是 Demo 截图。**  
有登录注册、HTTPS、ICP 备案、桌面三栏与手机底部导航两套布局。后端未启动时前端可 mock 演示，但线上走的是真实服务。

## 产品能力

| 模块 | 做什么 |
| --- | --- |
| 陪伴 | 文本 / 语音对话，SSE 流式回复，发送飞字，新窗口开场白 |
| 形象 | Live2D 舞台、换形象 / 换装、说话时嘴型同步 |
| 声音 | 浏览器识别优先，后端 ASR / TTS / 音色克隆兜底 |
| 人设 | 上传 `skill.md` 定义角色，多角色切换 |
| 生活 | 当天事件时间线 + 当前情绪，按时间槽生成 |
| 生产力 | 上传文件夹，用自然语言布置任务，下载产出 |
| 情绪 | 独立倾诉通道，与主记忆隔离 |

## 技术架构

```
浏览器（Vue 3 + Vite）
    │  /api  /agent  /emotion
    ▼
Nginx 反代
    ▼
Flask 后端（独立仓库 Galatea）
    ├── 短期记忆 / 长期记忆（FAISS）
    ├── TTS / ASR / 音色克隆
    └── 生活事件与情绪状态
```

前端无全局状态库。接口集中在 `src/api/index.js`，开发态由 Vite 代理到本机后端；生产环境用相对路径 + Nginx 反代，避免把后端端口暴露到公网。

主要界面：

- 桌面：左侧人设，中间舞台 / 生活 / 生产力 / 情绪，右侧对话
- 手机：聊天优先，底部切换角色、陪伴、生活、生产力、情绪

## 快速开始

需要 Node.js 18+。

```bash
npm install
cp .env.example .env
npm run dev          # http://localhost:5173
```

```bash
npm run build
npm run preview
```

| 变量 | 说明 |
| --- | --- |
| `VITE_API_BASE` | 后端绝对地址。生产部署留空，走相对路径反代。 |
| `VITE_PROXY_TARGET` | 开发代理目标，默认 `http://127.0.0.1:8001`。 |
| `VITE_USE_MOCK` | 设为 `1` 时不请求后端，仅演示界面。 |

## 说明

- Live2D 默认加载公开 CDN 模型，离线需改为本地路径。
- Live2D 画布不能用 `display: none`，模式切换使用 `visibility`，避免纹理丢失。
- 浏览器语音识别主要在 Chrome / Edge 可用。

## 技术栈

Vue 3（Composition API）、Vite 6、marked、oh-my-live2d。
